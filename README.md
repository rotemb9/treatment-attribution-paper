# treatment-attribution-paper

This repository contains the data and R code used to reproduce the analyses, Bayesian model simulations, and figures reported in:

Botvinik-Nezer, R., Kwon, M., Jones, M., & Wager, T. D.
Misattributing recovery: A belief-systems account of medical treatment beliefs

The figures/ directory is created automatically by the analysis scripts and contains the manuscript figures and intermediate figure objects.

**Data:**
vignettes_data_combined.csv is the de-identified, analysis-ready dataset used for the analyses reported in the manuscript.

The dataset contains 851 vignette-series observations from 566 participants. All participants completed one four-week vignette series, and 285 participants completed a second series. Participant exclusions were applied before creation of this analysis-ready dataset, as described in the Methods section of the manuscript.

Each row corresponds to one vignette series for one participant.

Main variables

src_subject_id: anonymized study-specific participant identifier

vignette_version: vignette condition/version

vignette_gender: gender of the patient described in the vignette

vignette_symptoms: symptom-severity condition (Low, Med, High)

vignette_alternative_treatment: alternative-treatment condition (a = over-the-counter drug, b = rest, c = vitamins)

vignette_outcome: outcome condition (R = recovery, NR = non-recovery)

Q1: belief in the effectiveness of the main treatment after observing the outcome

Q3: belief that the patient had COVID-19

Q4: belief in natural recovery without treatment

Q6: belief in the effectiveness of the alternative treatment

Q8: belief in the potential effectiveness of the main treatment without outcome information

gender: participant gender

age: participant age

All belief measures were collected on scales ranging from 0 to 100.

**Analysis code**

The analyses were conducted in R.

model_simulations.R implements the Bayesian belief-systems model and generates the simulated model predictions used in Figures 1A, 3A-B, and S1.

analyze_vignette_data.R performs the statistical analyses reported in the manuscript and generates the empirical panels used in Figures 1-3 and the Supplementary Figure.


Reproducing the analyses

Run the scripts from the root directory of the repository.

First, generate the Bayesian-model simulation objects:

source("code/model_simulations.R")

Then run the empirical analyses and generate the manuscript figures:

source("code/analyze_vignette_data.R")

The second script uses simulation objects generated by the first script, so the scripts should be run in this order.

Generated figure files are saved in the figures/ directory.
